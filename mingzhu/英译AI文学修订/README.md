# 英译AI文学修订

本目录为 **英译 → 中文 AI 文学修订** 整包（28 部），供公开浏览与产品终审参考。

## 与 `作品/` 的区别

| | `mingzhu/作品/` | `mingzhu/英译AI文学修订/` |
|---|---|---|
| 性质 | 可核 **民国／公版白话** 译本全文 | **非民国公版**；对照用户提供的英文底本，由 AI 做中文翻译与文学修订 |
| 用途 | 听读制作候选正文 | 分龄试读、编辑手册／对照、设备接入索引 |
| 版权 | 按各书公版证据入库 | 编校未经外部译者或出版社终审；产品方自行终审后启用 |

二者并列，**互不覆盖**。白话公版书目仍以 `作品/` 为准。
