## 一、原作考察：市场上已有的成熟改编体系

检索到并下载了 31 张真实原作内页样本（见 `board_originals.jpg`），归纳为四类成熟范式：

### 范式 A：台版儿童名著漫画（《世界文学名著漫画系列》，电子工业出版社 2012，赖有贤团队）

20 册，覆盖《安徒生童话》《格林童话》《一千零一夜》《伊索寓言》《爱丽丝漫游奇境》《木偶奇遇记》《绿野仙踪》《小王子》《海底两万里》《鲁滨逊漂流记》《金银岛》《爱的教育》《大人国小人国》《地心游记》《彼得潘》等。

- **开本** 16 开平装，单册 118–124 页
- **分格** 每页 2–4 格，多用「一宽两窄」「上二下一」的不等分格；跨页可铺开
- **画风** 全彩、粗描边、圆润可爱、表情夸张
- **文字** 每话独立成章，格内配旁白框 + 对话框，文字量远大于欧美图像小说
- **优点** 文字承担叙事，适合识字量低的低龄读者
- **对本项目的价值**：**分格骨架**直接可用。旁白框承担故事推进，是 6-8 岁段的关键设计

### 范式 B：中国连环画（《三国演义》上海人美 1957 /《西游记》河北人美 / 钱笑呆&赵宏本《孙悟空三打白骨精》）

- **分格** 每页 1 幅为主，大开幅，讲「连续画」逻辑；页眉带话名（如「虎牢关」）
- **画风** 纯黑白线描、工笔+速写混合、白描写实、背景扎实、构图讲究纵深
- **文字** 每页独立文字块 + 画外音（旁白），承担全部叙事
- **优点** 黑白线描技法的教科书级参考
- **对本项目的价值**：**黑白线稿质感与写实分寸**的标准。证明「纯黑白、无网点」完全能承担严肃题材

### 范式 C：蔡志忠水墨漫画（四大名著，22 册《西游记》/ 10 册《三国演义》等）

- **分格** 每页 3–6 格，方格为主、竖向长格穿插，节奏紧凑
- **画风** 粗犷简笔、水墨线条、大量留白、造型夸张
- **文字** 每格对白短促，「弹幕」式吐槽
- **优点** 幽默解构，适合降低理解门槛
- **对本项目的价值**：**格数与节奏**参考。9-12 岁段可用更密的分格承载复杂情节

### 范式 D：欧美图像小说 / 章节书（middle grade graphic novel）

- **分格** 2–6 格，格子尺寸差异大，强调气氛与留白；跨页大图作章节转折
- **画风** 黑白线稿 + 网点（screentone），笔触自由，透视大胆
- **文字** 旁白框为主、对白框为辅，密度低，靠画面叙事
- **对本项目的价值**：**9-12 岁段的画面叙事密度**标准。无网点纯线稿是「可上色」版本的关键差异

### 附：四格漫画模板类（小红帽四格漫画连环画线稿模板等）

市面大量「可打印 A4/A3、8K 黑白线稿」的四格连环画素材，说明**黑白线稿 + 可打印**是有明确付费需求的成品形态。

## 二、核心结论（已实机验证）

### 1. 黑白线稿 + 绘本分格 + 空白气泡：本项目已跑通

验证图：`poc/poc_6_8.jpg`（6-8 岁，3 格）、`poc/poc_9_12.jpg`（9-12 岁，5 格变式）

- 纯白底、纯黑线、无网点、无灰阶 —— **可直接上色**
- 分格边框粗细一致、白缝均匀
- 对白气泡留白、无任何文字（AI 生成文字必然糊，故全部留白，文字后期排版）
- 画面中偶有拟声词/单字渗入（如「啊」「耶」），**属缺陷**，需在后期用矢量修掉或改由排版层处理

### 2. 角色一致性：用「单角色三视图设定表」做参考图可稳定保持

验证图：`board_charsheets.jpg`（4 张设定表）、`board_poc_consistency.jpg`（一致性验证）

方法（关键）：

1. **每个角色单独出一张三视图设定表**（正面 / 四分之三 / 侧面，同一张图内三个全身像）
2. 出正文页时，把该角色**单张设定表**作为 `input_urls` 传入
3. 一页涉及多个角色时，传入**各自独立的**设定表 URL（不要传合照）
4. 提示词中重复强调「保持与参考图完全相同的脸 / 服装 / 道具」

实测结果：

- 悟空：4 格内头箍卷纹、脸部纹样、袍子系带、金箍棒完全统一，无漂移
- 小红帽：2 格内发型、兜帽轮廓、裙装一致
- 代价：单页参考图越多，模型越容易把角色特征「平均化」。**建议每页参考图不超过 3 张**

### 3. 分龄差异不是「画得糙一点」，而是分格数与文字密度

| 维度 | 6-8 岁 | 9-12 岁 |
|---|---|---|
| 每页格数 | 2–3 格 | 4–6 格 |
| 主导叙事 | 旁白框 + 对白（旁白为主） | 对白 + 少旁白 |
| 文字量 | 每页约 30–50 字 | 每页约 60–100 字 |
| 画风 | 圆润、粗描边、大眼、简化背景 | 粗犷简笔 / 写实线描、表情与动作戏 |
| 角色 | 1–2 个 | 3–5 个 |
| 景别 | 中远景为主 | 远近景穿插、特写强调情绪 |
| 页数/章节 | 一话 6–8 页 | 一话 10–14 页 |

> 用户设定的「一页 50 字符」量级与 6-8 岁段吻合。9-12 岁段可放宽到 60–100 字。

## 四、生产流程（每部作品）

```
Step 1  改编脚本      选定章节 → 拆成 N 话 → 每话写分镜表（格号 / 景别 / 画面描述 / 旁白 / 对白）
Step 2  角色设定表    每角色 1 张三视图（正面 / 四分之三 / 侧面），黑白线稿，纯白底
Step 3  分镜预演      每话 1 张「缩略分格草图」，确认节奏与格数（可选）
Step 4  正文出图      逐页生成，input_urls 挂该页涉及角色的独立设定表
Step 5  一致性自检    对照设定表核对：脸 / 发型 / 服装 / 道具 / 配色留白
Step 6  修版          去除渗入的拟声词与乱码；统一气泡与边框
Step 7  排版          后期把旁白/对白填入留白气泡与旁白框（不依赖 AI 写字）
```

**参数基线**：`aspect_ratio` 按目标开本定（16 开竖向用 3:4，跨页用 16:9），`resolution` 2K（4K 收益小、耗时翻倍），线稿页建议统一 `4:3` 起做再裁。

## 五、提示词模板（已验证）

**通用前缀**

```
Black and white manga comic page, clean black ink line art on pure white background,
NO color, NO gray shading, NO screentone, pure white background.
```

**分格描述**

```
Layout: N comic panels of varying sizes on one page,
thick clean black panel borders, even white gutters.
```

**角色一致性段（配合 input_urls）**

```
The SAME character as in the reference image appears in every panel,
keeping exactly the same face, hairstyle, clothing design and props.
```

**结尾硬约束**

```
Empty blank speech bubbles with no text.
NO text, NO letters, NO words anywhere in the image.
```

**6-8 岁追加**

```
Simple friendly cartoon style for children aged 6-8,
big round eyes, small bodies, bold clean outlines, minimal background detail.
```

**9-12 岁追加**

```
Expressive manga style for children aged 9-12,
bold varied line weight, dynamic camera angles, clear silhouettes, detailed clean background props.
```
