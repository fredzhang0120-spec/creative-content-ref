# 提示词模板（已实机验证）

## 通用前缀

```
Black and white manga comic page, clean black ink line art on pure white background,
NO color, NO gray shading, NO screentone, NO halftone, NO filled gray areas.
```

> **注意**：`NO gray shading` 之外必须加 `NO filled gray areas`。
> 實測模型會在遠景（森林、天空、大面積背景）自動加灰階填充，僅寫 `NO gray shading` 不足以阻止。

## 分格描述

```
Layout: N comic panels of varying sizes on one page,
thick clean black panel borders, even white gutters.
```

## 角色一致性段（配合 input_urls）

```
The SAME character as in the reference image appears in every panel,
keeping exactly the same face, hairstyle, clothing design and props.
```

## 结尾硬约束

```
Empty blank speech bubbles with no text.
NO text, NO letters, NO words anywhere in the image.
```

> 實測模型會滲入擬聲詞與單字（如「啊」「耶」），屬缺陷。策略是**所有文字一律留白**，
> 後期用矢量排版填入旁白框與對白框——這是唯一可靠解。

## 6-8 歲追加

```
Simple friendly cartoon style for children aged 6-8,
big round eyes, small bodies, bold clean outlines, minimal background detail.
```

## 9-12 歲追加

```
Expressive manga style for children aged 9-12,
bold varied line weight, dynamic camera angles, clear silhouettes, detailed clean background props.
```

## 混合路線（推薦，依實測三路對照結論）

```
Minimal confident line art: characters drawn with few clean strokes,
bold simple outlines, generous white space inside panels,
sparse but charming simple background.
```

## 角色設定表提示詞骨架

```
Character reference sheet, black and white clean ink line art on pure white background,
NO color, NO gray shading, NO screentone.
ONE character only: [角色特徵描述].
Three full-body views side by side on one sheet: front view, three-quarter view, side view.
Same character drawn identically in all three views, standing straight, neutral standing pose,
arms slightly away from body, full body visible head to toe.
[年齡段畫風要求]
No background, no props, no other people, no text, no letters, no numbers, no labels.
```

## 生成參數

- `aspect_ratio`：16 開豎向用 `3:4`，跨頁用 `16:9`，正文頁統一 `4:3` 起做再裁
- `resolution`：`2K`（`4K` 收益小、耗時翻倍）
- `input_urls`：傳該頁涉及角色的**各自獨立**設定表，一頁不超過 3 張
