## 为什么要分两层

本项目做的是「**公版故事 + 全新画面**」：

| 层级 | 内容 | 版权状态 | 本仓处理 |
|---|---|---|---|
| 故事 | 《西游记》《格林童话》《安徒生》《伊索》《爱丽丝》《鲁滨逊》《木偶奇遇记》等 | ✅ **公版**（作者逝世逾 50 年） | 可自由改编 |
| 原作画面 | 蔡志忠、赖有贤、上美连环画家们的具体造型与画面 | ❌ **仍在保护期内** | **不入库** |

理由很直接：

- 蔡志忠作品财产权保护至 **2074-12-31**（作者 1948–2024，终生 + 50 年）
- 赖有贤在世，保护期未届满
- 戴敦邦（1929–1995）→ 2045-12-31；赵宏本（1931–2005）→ 2055-12-31
- 本仓为 **public** 仓库，且仓库既有 `.gitignore` 明确写着「本地草稿／扫描；勿推公开仓」

所以：**原作扫描件只留在本机**（`research/_原作参考_不入库/`），
推上 GitHub 的是——原创资产、可复用方法论、以及每张原作图的来源与索引（指向来源站，不复制图像本体）。

## 本项目的画风结论

**混合路线（推荐）**：保留蔡志忠的线条简约与留白气韵，同时保证场景细节可读。

原作实测：墨量占比中位 **6.6%**（范围 1.5%–30%），均匀细线，无网点无灰阶，分格边框纤细。
本项目产出：墨量提到 **12–18%**，线条中等粗细，便于儿童上色与印刷还原。

原作值得学的三件套（均为通用版式手法，不构成对具体作品的复制）：

1. **頁邊豎排旁白塊** — 脱离分格独立排布的叙述文字条
2. **格內小數字編號** — 阅读顺序引导，低龄段尤其有用
3. **3–8 格/頁的疏密節奏** — 橫向 3 行最常見

## 角色一致性方法

每个角色单独出一张**三视图设定表**（正面 / 四分之三 / 侧面），
出正文页时把该角色**独立**的设定表作为参考图传入，一页参考图不超过 3 张。

实测：悟空 4 格内頭箍捲紋、臉部紋樣、袍子系帶、金箍棒完全統一；小紅帽跨場景無漂移。
關鍵：不要傳角色合照作為參考圖。

## 分齡差異

| 維度 | 6-8 歲 | 9-12 歲 |
|---|---|---|
| 每頁格數 | 2–3 格 | 4–6 格 |
| 主導敘事 | 旁白框 + 對白 | 對白為主，少旁白 |
| 每頁文字 | 30–50 字 | 60–100 字 |
| 畫風 | 圓潤、粗描邊、大眼、簡化背景 | 粗獷簡筆／寫實線描、表情動作戲 |
| 角色數 | 1–2 個 | 3–5 個 |
| 景別 | 中遠景為主 | 遠近景穿插、特寫強調情緒 |
