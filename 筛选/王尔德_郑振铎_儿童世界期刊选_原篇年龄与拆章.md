# 《王尔德童话·郑振铎〈儿童世界〉期刊选》· 原篇年龄与拆章

> **口径（写死）**：大陆；原作公版 ≠ 译本公版；**保持选定公版译本正文，不换篇不改情节**；不适龄只标年龄 / 家长陪读。  
> **入选门槛**：奥斯卡·王尔德童话；本册**仅**收郑振铎在《儿童世界》期刊上**单独署名**的白话篇，**禁止**用郑振铎+高君箴合集《天鹅》（高君箴1985卒→合著约至2035）。  
> **底本**：①《安乐王子》（《儿童世界》1卷1期，1922）②《少年皇帝》（同刊1卷3期，1922）③《自私的巨人》（同刊系郑单译，后入《天鹅》合集——**制作只锁期刊郑署正文**）。证据：杨焄《王尔德〈快乐王子〉早期汉语译介谫论》（澎湃·上海书评）、中国作家网等。  
> **与穆木天本关系**：表A已有穆木天泰东五篇；本册为**口语儿童向期刊另一译系**，并补穆本未收之《少年皇帝》。可并行，**勿串文**。  
> **本阶段不配音**。

| 项 | 结论 / 依据 |
|---|---|
| 译者 | **郑振铎**（期刊单独署名；**非**《天鹅》合署） |

| 译本形态说明 | 《天鹅·序》自承童话可用「重述」；《安乐王子》篇末注「根据原文而略有删节」。**属该公版译述固有形态**（类戴望舒删篇末韵文），制作时**保持期刊郑文、不另改情节、不回补当代全译** |
| **禁止** | 《天鹅》（郑+**高君箴**）；巴金《快乐王子集》（在保）；穆木天正文串入本册 |
| **译本结论** | **公版**（粗判，就**儿童世界期刊郑振铎单署译文**而言） |

**一句公版结论**：王尔德原作公版；郑振铎1958卒→约2009起公版；锁1922《儿童世界》郑单署三篇。勿用《天鹅》合集、巴金、穆木天串文。
